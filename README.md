Project Title: My Personal Portfolio 💻
This repository contains the source code for my personal portfolio website, designed to showcase my skills, projects, and professional background.

->Overview
This project meets the requirements for Mini Project 1: Personal Portfolio with Resume on Azure Blob. The site is a responsive single-page application focused on clean design and an interactive user experience.

->Key Features
Responsive Design: Optimized for viewing on desktop, tablet, and mobile devices.
Interactive Projects Section: Includes a dynamic expand/collapse feature for viewing in-depth details of each project (like the Rungta Fixit maintenance app).
Azure Blob Integration: A direct link is provided to download my resume, which is securely hosted on Microsoft Azure Blob Storage.
Clear Structure: Includes all required sections: Home/Personal Info, About Me (Skills), Projects, and Contact.

->Tech Stack 🛠️
Frontend:	HTML5, CSS3, JavaScript
Styling/Design:	Responsive Design, CSS Flexbox/Grid
Cloud Services:	Firebase (for potential future data integration or live demos)
Hosting:	Azure Blob Storage (for resume hosting)
Version Control:	Git / GitHub
