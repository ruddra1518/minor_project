Projects

Rungta Fixit - College Maintenance Reporting System

A responsive web application built with HTML, CSS, JavaScript, and Firebase for reporting and tracking maintenance issues with real-time updates.

Project Goal:

To streamline and simplify the process of reporting, tracking, and managing maintenance issues on a college campus, enhancing efficiency and communication between students and administration.

Key Features:

  • Responsive user interface for submitting maintenance requests.
  • Real-time tracking of reported issues using Firebase.
  • Admin panel for monitoring, updating, and resolving maintenance issues.
  • Automated workflows to reduce manual errors and improve reporting accuracy.
  • Front-end interactivity and smooth user experience with JavaScript.

Tech Stack:

  • Frontend: HTML, CSS, JavaScript
  • Backend/Database: Firebase (Authentication, Firestore/Realtime Database)
